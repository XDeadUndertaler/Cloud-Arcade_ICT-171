About the Project

The project is about a cloud-hosted website called “CloudArcade” that offers users access to a variety of entertaining and interactive minigames on a single online platform. The website features five browser-based games like Memory Match, Memory Paint, Number Guessing, Rock Paper Scissors, and Tic Tac Toe. Each game will be made using HTML, CSS, and JavaScript...
